## DiceUtils-js

A dice utils javascript front-end.

### Combinations

Allows counting and manipulating dice roll combinations.

### Preact UI - `index.html`

The `index.html` contains a Preact UI for the dice utils.
- `index.css` contains the styles.
- `view/app.js` contains the main app.
- `main.js` renders the main app.

### Mocha test page - `test.mocha.html`

The `test.mocha.html` runs mocha 
test on `./test.mocha/index.html`
